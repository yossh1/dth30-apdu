# tools/ について

調査で使った解析・実験ハーネス（Python）のアーカイブ。いずれも自作です。
多くは純正ファームのダンプや起動ストリームなど、本 repo に含まない入力
ファイルを前提とします（各自の機器から取得したものを使ってください）。
パスや前提は調査時のもののまま一般化してあるので、実行には各自の環境に
合わせた書き換えが必要です。

- `hw/` — 純正ファーム起動リプレイとメモリ観測のハーネス群（hw1〜hw28 系）
- `hw/legacy-stack/` — 初期の自作スタック実験（レガシー）
- `modeq-exp*/`、`hook-exp-20261123/`、`code-region-20261122/`、`phase2-20261122/` — 各実験の解析スクリプト
- `cfw-audit/` — 純正イメージの census・抽出スクリプト
- ルート直下の `*.py` — フラグマップ再抽出、文字列 xref、MMR census 等の単体解析ツール
